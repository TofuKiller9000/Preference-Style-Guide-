# Preference Style Guide

A technical documentation website demonstrating an overview of the ROE Dental Laboratory
account-specific preferences system. 

## Project Goals

- Establish a consistent documentation hierarchy
- Improve the readability and discoverability of information
- Create a replicable system that can be learned by anyone
- Provide a indexable department-specific interface
- Limit the amount of departments with preferences

## Run Locally

Open `index.html` in a browser, or use a local
static web server while developing.

## Deployment

1. Push the project to GitHub.
2. Open the repository's Settings.
3. Select Pages.
4. Choose deployment from the `main` branch and `/ (root)`
   if using the repository root.
5. Save and wait for deployment to finish.

## Project Notes

This is a portfolio presentation of documentation and
system-design principles. Examples must be sanitized and
approved for publication before deployment.
